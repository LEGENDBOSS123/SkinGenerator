Skin Generator AI

Pytorch Transformer that converts skins to sequence of custom tokens.

Steps how to run:

Create a .venv via: `python -m venv .venv` and activate it `source .venv/bin/activate`
- install stuff in requirements.txt `pip install -r requirements.txt`
- "avatars.json" is not created so unzip avatars.json.zip to get that


1. python preprocess.py
2. python train.py
3. python generate.py
